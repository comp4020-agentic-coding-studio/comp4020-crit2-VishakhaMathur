1. What was the breakthrough that moved the work forward?
- The biggest breakthrough was figuring out why the carousel images looked "vertically stretched" wasn't a sizing tweak — it was discovering that Astro's image service silently ignores a height prop that conflicts with the source photo's actual aspect ratio, so the HTML attributes and the real generated file disagreed, and the browser's default object-fit: fill distorted the image to fill that mismatched box. The breakthrough was refusing to treat it as "make it look less stretched" and instead going to look at the actual generated files with sharp to see what dimensions Astro had really produced. That's what turned a guess-and-check loop (nudge the height, look again, still wrong) into an actual fix — locking the display box with aspect-ratio + object-fit: cover in CSS, which is correct regardless of what the source photo's native proportions are. 

2. What did this work change about who I want to be as a software developer?
- I was amazed by how agentic AI can be used to make the software development quicker if you give the right prompts. As a software developer I need to learn how to use AI responsibly. Instead of writing code line by line, I need to learn how to orchestrate the autonomous system. We just need to design the workflow, set rules and reduce the risks. Because the output depends on giving clear goals, context and constraints to the AI rather than typing code on our own. We need to act as supervisors who manage the workflows that can write, test, debug and deploy the program rather than just writing syntax.
